500.7 nm, and the strangest line this catalogue holds. For sixty years, astronomers who found it in
nebulae believed it belonged to an undiscovered element and named it "nebulium." It turned out to be
ordinary, doubly-ionised oxygen — doing something it never does on Earth.

## Why it is "forbidden"

An excited oxygen atom can sit in the exact state that produces this line for a real, measurable
time before it drops back down and emits it — but only if nothing bumps into it first. Any collision
at all knocks the atom out of that state before it can, which is why you have never seen this line
in a lit room: ordinary air is far too dense. It takes a vacuum better than any laboratory on Earth
keeps, and a nebula's own near-emptiness is exactly that.

## Where it shows up here

Both the Orion Nebula and the Helix Nebula carry it, alongside H-alpha — real forbidden-line
emission from two very different real sources.
