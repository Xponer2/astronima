Собственное остаточное тепло радиоизотопного термоэлектрического генератора: настоящий, честный
непрерывный спектр вовсе без собственных линий — ничего резкого, потому что здесь ничто не
возбуждается до конкретного перехода, только светится от самой по себе температуры, как любой
горячий предмет.

## Почему это отсутствие и есть суть

Пустое показание — не сломанное. Навести инструмент на нечто, в чём этот каталог честно не находит
ничего для определения, и получить настоящее «линий не найдено» вместо выдуманного — та же
честность, которой держится любая другая цель здесь.
